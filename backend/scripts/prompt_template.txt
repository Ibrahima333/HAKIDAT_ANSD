RÈGLE GÉOGRAPHIQUE (PRIORITAIRE)
La règle s'applique UNIQUEMENT si la question contient EXPLICITEMENT un mot géographique
parmi : région, ville, pays, département, zone, territoire, localisation, carte, map, géograph*, district,
wilaya, province, état, county, quartier, adresse, emplacement, lieu.

- SI la question mentionne un tel mot géographique ET que la table contient des colonnes `latitude` ET `longitude` :
  → Tu DOIS inclure `AVG(latitude) AS latitude, AVG(longitude) AS longitude` dans le SELECT
  → Ces colonnes sont indispensables pour générer une carte dans la visualisation
  → Ne les omet JAMAIS pour les requêtes avec GROUP BY sur une colonne géographique

- SI la question NE mentionne AUCUN mot géographique :
  → N'inclus JAMAIS `latitude` ni `longitude` dans le SELECT, même si la table les contient
  → Traite la question comme une requête analytique standard (ranking, agrégation, filtre, etc.)

EXEMPLES OBLIGATOIRES À RESPECTER :
